# PvP-Utilities (Fabric 1.21.11)

Auteur : Laz3red / lazgoated

Fonctions :
- Reach Display : toujours affiché (0.00 sans coup récent), position déplaçable avec les boutons Reset / Cancel / Apply.
- Crosshair : le crosshair vanilla devient rouge (peut toucher) ou bleu (peut crit).
- Saturation : poulets dorés sur la barre de faim.
- Damage Tint : teinte de dégâts sur la peau et sur les armures.
- Hitboxes : couleurs, filtres, épaisseur, distance.
- Momentum : compteur de vitesse dans la barre d'xp, calqué sur HerosGotMotion (seuils avant/arrière, couleurs selon la vitesse, seconde barre, barre d'xp qui revient après un gain d'xp).
- Fullbright.
- Animation d'épée, compteur de totems, tab / scoreboard / nametag tweaks, changeur de temps et de météo (côté client).

Commandes : /hitboxes, /damage-tint, /crosshair, /reach, /saturation, /momentum, /fullbright, /swing, /totems, /tabtweaks, /scoreboardtweaks, /nametags, /timechanger, /weatherchanger, /hudscale (on / off), /hudscale <élément> <0-3>, /time <day|noon|sunset|night|midnight|moon|sunrise|reset>, /weather <clear|rain|storm|reset>
et /pvputils <fonction> <on|off>, /pvputils position.

Build : gradlew build -> build/libs/pvp-utilities-1.0.0+1.21.11.jar
